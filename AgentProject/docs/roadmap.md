# 开发路线

## 已完成

- Spring Boot + MySQL基础工程
- 四角色定义和演示数据
- 库存、订单、概览接口
- Ollama Qwen3:8B适配器
- Qdrant索引和检索适配器
- Vue企业运营工作台
- 飞书事件入口骨架

## 下一阶段

1. 增加MES设备、报工、质量、物料和工艺的只读工具
2. 增加MES文档解析、版本、有效期、权限和向量去重
3. 将Agent工具调用改成结构化JSON并增加参数校验
4. 实现“销售订单交付评估”固定工作流
5. 增加排产模拟和产能约束计算，不直接写回MES
6. 增加采购申请草稿和飞书人工确认卡片
7. 增加本地登录、角色权限和数据范围权限
8. 增加操作审计、请求追踪和模型调用耗时统计
9. 增加Markdown、PDF、Word知识文档导入
10. 增加Agent评估数据集，测试准确率、工具选择和越权情况

## 第一条完整业务闭环

```text
销售订单
  -> 查询库存
  -> 评估生产能力
  -> 计算物料需求
  -> 生成采购申请草稿
  -> 飞书人工确认
  -> 记录协作和审计结果
```

这条闭环优先于分别开发四个“大而全”的Agent，因为它能够同时验证业务模型、角色权限、工具调用、工作流和飞书协作。
